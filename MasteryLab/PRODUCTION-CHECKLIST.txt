MasteryLab — production checklist (step 4)
==========================================

1) appsettings.Production.json
   - ConnectionStrings:DefaultConnection → real SQL Server / LocalDB for prod host
   - OwnerEmail → your admin email
   - Do not commit passwords

2) Database
   Add-Migration Initial (or latest)
   Update-Database
   Confirm Levels, Subs, AppointmentPlans exist

3) Hosting
   - ASPNETCORE_ENVIRONMENT=Production
   - HTTPS certificate
   - Disk space for wwwroot/uploads/lessons (videos)

4) Limits (already in code for upload ~100GB — host may need higher Kestrel/IIS limits)

5) Smoke test
   Register owner → Admin bar
   Free first lesson → video → exercises
   Subscribe mock → open another course
   Book private lesson
   Teacher upload one short video

6) Optional later
   Real payments, SMTP email, CDN for video
